# Victory review concept

The original concept was generated with the built-in imagegen tool and approved by the user. `victory-concept.png` remains a static reference with illustrative amounts. The design is now implemented in the local game through `dist/victory.js` and `dist/victory.css`, using `dist/assets/victory-crest.png` as transparent decorative artwork and real HTML for all text and actions. Its exact production prompt is in `dist/assets/victory-crest.prompt.txt`.

`implemented/` contains browser captures and the eight-size layout measurements. The UI was checked from 320×480 through 3440×1440. A genuine final-card win, immediate first place at a four-player table, Watch table, final results without a repeated reward, rematch buy-in, Back to tavern, keyboard focus, later escape, and reduced-motion loss were verified in isolated QA saves. All 129 unit tests passed; the complete output is in `test-results.txt`. The user's normal saved game was not used for the fixtures.

Regenerate disposable review pages with `node scripts/prepare-victory-review.mjs`, then open the reported localhost URL with `?qa`. The generated `dist/test-victory-*.html` pages are disposable and are not part of the normal game flow.

## Generation prompt

Use case: ui-mockup. Create ONE polished 16:9 art-direction concept for the VICTORY screen of this exact local fullscreen fantasy tavern card game. Reference image is style and world reference, NOT an edit requiring preserving obsolete layout. Keep recognizable full-screen sandstone playfield surrounded by carved walnut, bronze/gold, forge glow at left and teal lantern at right, illustrated collectible-card-game aesthetic. The user currently has a tiny crown and plain text. Show a genuinely rewarding premium yet tasteful final result: dim and gently defocus peripheral board seats, use warm focused theatrical golden light at center. A substantial but elegant central victory composition occupying middle 55% width and 65% height, sculpted walnut-and-antique-gold crest with emerald fabric accents. Top sculpted luminous gold laurel and crown with four tiny card-suit motifs (no poop trophy; poop is loser identity). HUGE beautiful readable ivory/gold lettering exact 'YOU WIN'. Under it small exact 'Dignity intact.' Then a generous tactile golden coin medallion and exact '+30 COINS', with a small caption exact '40 collected · 10 buy-in'. These are illustrative example amounts. Secondary small humorous line 'The Fox is the Shithead.' Below integrated ornate emerald/gold primary button exact 'PLAY AGAIN', with quiet text link 'Back to tavern'. Give clear text hierarchy and breathing room. The player is the hero; no irrelevant stat cards. A few warm embers and gold sparks at edges; no confetti overload, no blinding explosion. Painted 3D crafted materials with believable shadows, cohesive with reference. Environment still clearly visible at edges, do not create generic flat app modal or rectangular dashboard. Omit unrelated original UI labels and opponent cards in the center. This image is a static concept, not an implementation screenshot. Output landscape 1536x1024 or 16:9.

Reference: artifacts/board-fixtures/desktop.png

Implementation direction: generate decorative transparent assets separately; retain real responsive HTML text, actual accounting values, and native buttons. Distinguish first place and pot ownership from a later escape in multiplayer.


## Final typography pass

The production result now uses self-hosted Cinzel Decorative Black, Cinzel Bold and Cormorant Garamond SemiBold Italic, with a restrained gold bevel and a finite title highlight. Fonts total 53,536 bytes (about 52 KiB); exact downloads and full OFL licenses are retained under `dist/assets/fonts/`. `typography/layout-checks.json` records 60 checks: win, longest-name, guest/host-waiting, loss, first-out and practice states at ten sizes from 320×480 through 3440×1440. All text and controls stayed on screen without horizontal clipping. The maximum standard payout (400 pot, 100 buy-in, +300 net) was included. All 134 tests passed; final output is in `typography/test-results.txt`. The runtime continues to use only local font files.
