# Aiming ribbon references

- [SlotVFX: Ribbon trails](https://docs.slotvfx.com/guides/ribbon-trails/) — width/opacity profiles, animated flow along a strip and keeping strand counts bounded. Used as technical and motion inspiration; no third-party code or art copied.
- [Three.js examples](https://threejs.org/examples/) — browser GPU effects reference. The implementation uses native WebGL and introduces no Three.js dependency.

The authored result uses cubic geometry, a procedural moving core/sheath/filament, geometric metal facets and a target reticle in the existing Ember Hearth palette. This completes the drag-arrow refinement; broader cinematic-plan proposals such as click-to-arm targeting and character cinematics remain separate work.
